# MiniMax LH 与 Rotation+GPTQ：公开 240 条 prompt 复测

[English](README.md) | [简体中文](README.zh-CN.md)

完成时间：2026-11-16 14:14:12，Asia/Shanghai（UTC+08:00）。

本次重新采集同环境 MXFP8 基线，先测 LH 三轮，再测 RT 三轮；使用同一组 4 张 GPU。数据来自当前 repo 的公开 240 条 prompt，四类各 60 条，每条生成 32 个 token，评分全部 32 个位置。

参考模型：`amd/MiniMax-M3.1-Flash-Quark-MXFP8-1026`。候选模型：`amd/MiniMax-M3.1-Flash-Quark-MXFP4-LH-Test`（Local Hessian）和 `amd/MiniMax-M3.1-Flash-Quark-MXFP4-RT-Test`（Rotation + GPTQ）。

## 三轮均值

| 模型 | 平均分桶 KL（nat）↓ | 同前缀 Top-1↑ | 完整 32-token↑ | 三轮评测总耗时（分钟） |
|---|---:|---:|---:|---:|
| LH | 0.03843885 | 96.21% | 34.31% | 36.79 |
| RT | 0.04018061 | 95.93% | 33.89% | 40.98 |

三轮共计每模型 720 条序列、23,040 个同前缀位置。LH 完整序列匹配 247/720，RT 为 244/720；Top-1 匹配分别为 22166/23,040 和 22103/23,040。

相对 LH，RT 的 KL 高 4.53%，Top-1 低 0.27 个百分点，完整 32-token 低 0.42 个百分点。本次没有显示 RT 的总体保真度优势；差距较小。本轮未重测普通 MXFP4，因此无法据此判断两种算法相对普通 MXFP4 的提升。

## 三轮极差

| 模型 | KL 极差（nat） | Top-1 极差（百分点） | 完整 32-token 极差（百分点） |
|---|---:|---:|---:|
| LH | 0.00184735 | 0.55 | 1.67 |
| RT | 0.00100723 | 0.20 | 1.67 |

极差为三轮最大值减最小值。RT 本次的 KL、Top-1 极差较小，完整序列极差相同。仅三轮不足以证明普遍的稳定性优势。

## 口径与环境

6 轮均完整完成，零错误。每轮有限 KL 位置均为 5,062/7,680（65.91%），且位置集合完全相同；另外 2,618 个位置的基线概率接近确定，无法从返回概率分辨有限分桶 KL。Top-1 仍统计全部位置，完整序列一致率仍以 240 条为分母。KL 在每条 prompt 内对可计算位置取平均，再对 240 条 prompt 及三轮取平均。

LH 无需额外 rotation 支持；本次统一复用已经包含 vLLM #65918 和 AITER #7565 的环境。RT 使用 `VLLM_ROCM_USE_AITER=1`、`AITER_BYPASS_TUNE_CONFIG=1`、`--moe-backend aiter`，日志确认 `AITER_MXFP4_MXFP4`。本次未新增源码补丁。两候选均为 TP4、NVFP4 KV cache、`raw_logprobs`，评测 temperature=0、concurrency=2。完整 commit 和镜像信息见英文版。

新基线采集耗时 88.74 秒。上表时间不含服务启动和接口检查。本次所有 server 已关闭。逐轮指标与具体起止时间见 [英文 README](README.md)，原始输出留在本地实验目录。

这些指标衡量对 MXFP8 的保真度，不能当作任务答题正确率；也不能和旧环境、旧基线或历史 300 条 prompt 的数据直接混比。
